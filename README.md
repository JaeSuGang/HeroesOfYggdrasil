## 프로젝트 개요
- **장르**: CO-OP 3인칭 로그라이크 디펜스
- **프로젝트 기간**: 2025.02.18 - 2025.04.30
- **개발 인원**: 6명
- **엔진**: 언리얼 엔진 5.5

## 주요 특징
- **세계관 및 테마**: 세계의 마지막 보루인 세계수, 그것을 지키려는 자들과 파괴하려는 자들의 전투
- **게임 플레이**: 캐릭터 선태그 로그라이크적 특성 선택을 통한 성장, 웨이브 디펜스, 협동 등

## 게임 플레이
1. **기본 조작**  
   - WASD : 이동, Alt : UI 선택, Shift : 구르기, 마우스 : 화면 전환 및 공격, QER : 스킬 사용
     
2. **주요 시스템**  
   - 준비 단계 : 특성 선택 및 캐릭터 정비
   - 전투 단계 : 적 유닛들이 외부에서 진입
   - 특성 선택 : 매 웨이브를 클리어하면 랜덤으로 특성을 선택하여 캐릭터를 강화
     
3. **스크린샷 / 영상**
